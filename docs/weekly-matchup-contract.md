The model worker exposes public `WeeklyBoxScores`, `BoxScore`, `BoxTeam`, `BoxPlayer`, `PlayerTeamHistory`, and `BoxScoreContext`. `PlayerTeamHistory::new(Season)` partitions an explicit player→pro-team history by season. `BoxScoreContext<'a>` contains public `season`, `scoring_period`, `matchup_period`, `now_unix_ms: i64`, and `history: &'a mut PlayerTeamHistory`. The output exposes season/scoring_period/matchup_period and `matchups: Vec<BoxScore>`, with `for_team(TeamId) -> Option<&BoxScore>`. BoxScore has optional home/away BoxTeam sides, optional id, matchup type/playoff metadata. BoxTeam has team_id, score, projected, lineup. BoxPlayer embeds the existing Player, exposes weekly actual/projected points and numeric-ID breakdowns, resolved pro-team/opponent, opponent positional rank, game_date_unix_ms, game_played (document the Python 0/100 kickoff-plus-three-hour heuristic), on_bye_week and lineup slot information.
